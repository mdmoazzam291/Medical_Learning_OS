# Source-grounded Concept Dossier sections

The Library Overview now groups text from exact **published canonical note versions** using explicit Markdown headings. It does not infer diagnoses, construct medical assertions from a question explanation, complete missing notes, establish mastery or publish content. The same presentation component renders a clearly labeled unreviewed draft within the pre-existing isolated Admin preview.

Recognized headings: Overview/Definition/Summary → Essential understanding; Foundations/Anatomy/Pathophysiology/Risk Factors → Foundations & mechanisms; Presentation/Symptoms/Signs → Clinical presentation; Diagnosis/Investigations/Interpretation → Diagnostic reasoning; Differential Diagnosis → Differential diagnosis; Management/Treatment/Follow-up → Management. Unrecognized headings and unheaded paragraphs are preserved as Additional reviewed material with original text and headings.

Each excerpt identifies its exact note version, and shows attached source titles and versions where available. Missing source records stay unresolved. Rendering is bounded to 24 excerpts; full versioned Notes are the authoritative fallback. An optional Recall-before-rereading link uses the existing nonscored self-review. Scored Study retains exclusive ownership of assessment evidence. No new content is created and source-rights/publication gates are unchanged.

This is a **P1 clinical dossier presentation improvement**, not a completed structured medical assertion registry, server-paginated content index, clinical problem ontology, typed relationship publication workflow or live-learning outcome validation. Each of those needs its own reviewable backend contract.

Acceptance: Node tests cover exact heading-only classification, unrecognized text, missing source references, version separation and literal preservation. GitHub core/browser/WebKit checks must pass before merge. The production catalog is empty; real-item publication and authenticated live browser acceptance remain blocked until reviewed content and the appropriate browser session exist.
