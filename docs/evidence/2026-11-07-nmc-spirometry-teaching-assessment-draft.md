# Spirometry teaching and assessment draft

AI-authored original pilot for GM28.11, September 2024 NMC PDF page 324. Draft for clinical and source-alignment review. The proposed concept is Spirometric assessment of suspected COPD. This partial competency component covers report interpretation in simulation.

## Short teaching note

FEV1 is the volume exhaled in the first second of a forced expiration. FVC is the total forced expiratory volume. Calculate FEV1/FVC using values from the same report and unit. Identify whether the report is pre- or post-bronchodilator.

First inspect quality information. Acceptability and repeatability influence how confidently a report can be interpreted. Review the curves and operator comments when available. A report explicitly marked uninterpretable should prompt a request for a technically adequate assessment rather than a definitive spirometric conclusion.

In a compatible clinical context, GOLD uses a post-bronchodilator FEV1/FVC below 0.70 as the spirometric criterion for COPD. State what the report establishes and what still needs clinical assessment. A numeric ratio alone does not establish the cause of airflow obstruction.

## Proposed scoring rubric

Use four separately recorded criteria, scored 0 for absent/incorrect and 1 for explicit/correct: checks the supplied test quality, identifies post-bronchodilator status or the lack of a usable result, computes the ratio accurately where meaningful, and limits the conclusion to the evidence. Record requested assistance separately. There is no validated pass threshold yet. A clinically reviewed rubric must define acceptable alternative wording and critical errors before use.

Keep the repeated comparison and delayed case as distinct assessment versions. A score from this exercise measures interpretation in simulation. Observed spirometry performance and other pulmonary function interpretation components require their own assessment.
