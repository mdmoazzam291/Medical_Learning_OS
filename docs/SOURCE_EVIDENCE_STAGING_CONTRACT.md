# Offline staging request and receipt bindings

`prepareSourceEvidenceStagingRequest(candidate, actorId, options)` validates an exact candidate {requestId,packageId,packageVersion,expectedPackageDigest,cases}, snapshots ordinary data before asynchronous hashing, recomputes the existing package digest and rejects mismatches. It returns frozen {requestId,actorId,packageId,packageVersion,packageDigest,requestFingerprint}. Cases use the existing source-row evidence schema. Unknown fields and nonordinary descriptors/prototypes are rejected before copying.

Fingerprint SHA-256 binds canonical {contractId:'source-evidence-stage-request-v1',actorId,requestId,packageId,packageVersion,expectedPackageDigest,claimsDigest}. claimsDigest is SHA-256 of canonical validated claims sorted by caseId. Case order is irrelevant; actor, request and exact metadata remain bound. UUID strings preserve existing case-sensitive binding semantics. The 16 MiB limit applies to canonical UTF-8 after parsing; a future transport must separately cap incoming bytes before parsing. This function neither authorizes actorId nor detects prior requests/conflicts.

`matchesSourceEvidenceStagingReceipt(receipt, expectedBinding, options)` returns Promise<boolean>. It checks exact ordinary receipt shape, all binding fields, UUID receiptId, valid canonical millisecond UTC recordedAt, contractId 'source-evidence-staging-receipt-v1', sourceReviewOnly:true and false clinicalApproved/rightsApproved/examScopeApproved/learnerRelease. receiptDigest must equal SHA-256 of the canonical receipt without receiptDigest. Both inputs are captured before asynchronous hashing. Errors return false.

A matching checksum is not a signature, authentication, durable readback or proof staging occurred. Anyone can construct a self-consistent synthetic receipt. Obtain real receipts only from an authenticated trusted adapter and independently enforce current rights, exact revision, runtime/account status and withdrawal. No source-byte verification, URL, live package, grant, persistence, transaction, retry reconciliation, database/API wiring or publication capability is implemented. SOURCE_EVIDENCE_STAGING_PORT.md remains the future transaction contract.
