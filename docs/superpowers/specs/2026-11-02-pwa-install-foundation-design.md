# PWA install foundation

First bounded slice of the owner-approved 21October PWA roadmap, selected under continuous next-task authorization. Intent: preserve one website/backend while making home-screen identity and standalone launch explicit. Root manifest has stable id/start_url/scope `/`, Medretica name, standalone display and existing brand colors; install launches normal root/session routing, never a private query or Admin deep link. Reuse the existing approved two-page M artwork for192/512PNG icons and keep the current180Apple icon. Add static manifest/Apple standalone metadata to served app/public HTML. Do not lock orientation or add service workers, caches, auth/data changes, install prompts, forced updates, offline/sync or store/native-app claims.

Approaches: manifest-only install slice (chosen, smallest useful independent step); offline/cache/sync bundled with installation (deferred, requires private-content and account lifecycle design); native wrapper (deferred by approved roadmap). Existing app layout/palette choices stay intact. Installed icons/launch chrome are static brand surfaces, as with the existing Apple icon.

Serve the manifest and icons through the explicit public allowlist, correct manifest MIME on Node and static output, same-origin CSP and existing no-store policy. Cover manifest discovery on root and served pages, stable identity/launch URLs, actual icon decoding and local HTTP serving. Browser tests must consume the built bundle and inspect Chromium manifest parsing; WebKit verifies discovery/assets only. No claim of real iOS/Android installation, login persistence or OS standalone acceptance without a physical device. Preserve PR379 stagedv4/realAuth block and other unrelated work. New branch from main91a11aff, no production deployment or merge.

References: https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable and /Manifest/Reference (checked2November2026). Service worker is not necessary for this metadata slice; offline remains separate.
