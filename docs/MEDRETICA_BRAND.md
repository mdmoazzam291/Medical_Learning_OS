# Medretica brand contract

Current owner direction: 19 October 2026. Replaces provisional PARSE as the public brand; old PARSE branches/PRs are not release sources.

- Name: **Medretica**. Preserve this capitalization.
- Tagline: **Your Medical Learning Operating System**.
- Explanatory descriptor: **integrated medical learning platform**.
- Public site: https://medretica.com . Evrani remains a backup name only.
- Repository, deployment resources, learner IDs, storage keys, permissions and API names retain their existing technical identifiers.

## Logo version 1

`web/medretica-mark.svg` is the canonical 64 × 64 symbol: three separated leaves, with a centered upper leaf and mirrored lower leaves. It follows the three-leaf direction in the latest Medretica welcome-screen mockup. No finalized vector master was recovered; the exact SVG geometry is this implementation's interpretation of that direction, not a claim of pixel-identical tracing or an earlier approved vector file.

Headers render that one asset as a CSS mask in the selected palette accent, including light/dark appearance and forced-colors mode. Decorative marks are hidden from screen readers; the home link identifies Medretica. Use the full name on wide layouts and the symbol alone where needed to retain workspace and account controls on phones/tablet portrait. Do not restore MLOS or m. as the public lockup.

`web/favicon.svg` uses the same paths, scaled inside a Sage Precision #244A3A rounded tile with #DDE8DC leaves. `web/apple-touch-icon.png` is its 180 × 180 rasterization for iOS home-screen bookmarks. HTML versioned icon links refresh the old cross favicon; native device icon refresh behavior is browser-controlled. No web-app manifest or standalone native app is introduced.

Titles, descriptions, application names and primary Open Graph text use Medretica. Public policies retain their approved operator and service copy; paid plans remain unavailable. Payment-provider display-name approval and provider-hosted logos are separate account state and are not changed by this website update.
