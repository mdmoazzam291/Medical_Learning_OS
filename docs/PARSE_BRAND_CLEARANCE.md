## Product scope for comparison

PARSE is intended for web/PWA/mobile medical education and assessment: NEET-PG / INI-CET preparation, QBank, clinical cases, adaptive learning, learner models, teaching, spaced revision, lifelong medical competency, and future institutional software. It is not currently a biotech sequencing service or an insurance/medical-claims processing service. Similarity is evaluated by mark **and** relatedness of goods/services, channels, audiences, and possible confusion; class numbers alone neither establish nor dismiss a conflict. See USPTO: https://www.uspto.gov/trademarks/search/likelihood-confusion

Initial classes to investigate:
- **41:** medical educational and training services / examination preparation
- **42:** software as a service, adaptive learning and cloud platform
- **9:** downloadable applications/software if supplied
- Additional classes only when actual goods/services require them. Avoid assuming a current clinical-care offering.

WIPO/Nice classification reference: https://nclpub.wipo.int/

## Acceptance gate before public PARSE adoption

1. **Official India review:** check exact PARSE and confusingly similar word/device marks in Class 9, 41, 42 and adjacent related descriptions in the official register. Capture application number, proprietor, mark representation, class, goods/services, filing/priority date, current status, territorial scope, opposing records and downloadable/search receipt where possible.
2. **Actual-use review:** check major India medical education, healthtech, SaaS businesses, app stores and searchable corporate names for confusing marketplace use, including unregistered names. Include phonetic and combined name variants, not merely the exact spelling.
3. **International future-use review:** evaluate USPTO records for 90268793 and 99638586, WIPO Global Brand Database/Madrid designations, and UK/EU later if targeted. Confirm live status from official records.
4. **Written risk disposition:** establish legally acceptable use of `PARSE` *as a word mark*, the descriptor `The Medical Learning OS`, matching logo, and the specified products/territories. A stylized logo or adding a generic descriptor does not automatically cure a conflicting word mark.
5. **Owner go/no-go:** only then authorize final vector logo, domain purchase, brand-based email/social handles, trademark filing as advised, PR deployment and public site/app rebranding.
6. **Fallback if negative:** retain Medical Learning OS as architecture and repository identifiers, choose a more distinctive candidate brand, then repeat searches. Do not rename auth, DB, event streams, clinical content or stable identities for a cosmetic brand decision.
