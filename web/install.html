Install Medretica

Add Medretica to your Home Screen or desktop for a separate app window. Keep an internet connection; offline study is not available.

iPhone or iPad · Safari

  1. Open Medretica in Safari, then open the Medretica homepage above.
  2. Tap Share and choose Add to Home Screen. It may be under More or additional Share actions.
  3. If offered, turn on Open as Web App. Confirm Add, then launch the new icon from your Home Screen.

Android · Chrome

  1. Open the Medretica homepage in Chrome.
  2. Open More, then Install and create shortcut → Install when offered. Some versions use Install app or Add to home screen.
  3. Follow the browser prompts and open the new entry from your home screen or launcher.

Desktop · Chrome

Open the Medretica homepage and use the address-bar install control or Chrome’s menu option to install the page as an app, when available. Follow the browser prompts, then launch its new entry. Menu labels and support vary.

Chrome computer instructions

If installation is missing

If you opened this link inside another app, open the same Medretica homepage in Safari on iPhone/iPad or Chrome on Android. Embedded browsers may omit installation controls. Check the browser menu as well as the address bar; labels vary by browser and version.

A Home Screen shortcut that opens a normal tab is not a standalone launch. Recheck the browser’s install options. Install from medretica.com for your normal account. A separately labelled Medretica Preview is a different installation and does not support accounts.

After installation

  1. Launch the Medretica icon. Check that it opens in its own app window, rather than an ordinary browser tab.
  2. Sign in from the installed app if asked. Browser and installed-app sessions may differ; do not assume your browser sign-in carries across.
  3. Use Medretica’s Home link and navigation menus to move between pages when browser controls are absent.
  4. Check portrait and landscape, then close and reopen the app when you are not answering a question. Confirm that your expected account appears.

If the page cannot load, check your internet connection and reopen it. Avoid clearing site data or reinstalling as a first troubleshooting step: doing so may remove local preferences and sign-in state. Only refresh or close a study session once your work has been saved.

Installation does not add offline study, notifications or extra account access. Support and menu labels vary by browser and operating system.
